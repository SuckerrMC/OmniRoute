# Agent OS for OmniRoute

OmniRoute already runs locally on Windows and Claude Code is configured, according
to the operator. Agent OS adds a repeatable development workflow to this existing
setup. Installation, provider accounts and global Claude settings are not replaced.

Goals: reproducible changes, documented decisions, verified tests, and explicit
cost control using only models the operator has verified as free for their account.
A catalog entry alone proves neither availability nor zero cost.

Milestones: repository workflow prepared; local model inventory pending; role model
selection pending; first locally validated feature pending. No Windows runtime or
local provider verification has been performed from this remote workspace.
